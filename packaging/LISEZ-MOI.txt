Temhalo — Windows x64

1. Extraire TOUT le dossier Temhalo de l'archive ZIP dans un dossier utilisateur.
2. Lancer Temhalo.App.exe. Ne pas déplacer l'EXE seul : les DLL, Assets et config sont nécessaires.
3. Au premier clic sur Démarrer, MediaMTX et FFmpeg sont téléchargés depuis leurs releases officielles GitHub et vérifiés par SHA-256. Une connexion Internet est nécessaire une seule fois par version des outils.
4. Dans OBS : serveur rtmp://127.0.0.1:1935/live ; clé stream ; H.264/AAC, CBR, intervalle d'image clé 1 s.
5. Dans Diffusion, ajouter les plateformes, puis suivre le guide OBS. Les commandes du délai sont sur Direct. Voir GUIDE-RAPIDE.md.

.NET 8, ASP.NET Core 8 et Windows App SDK sont inclus. Aucun SDK/Visual Studio ni droit administrateur requis. Garder le dossier complet.
Réglages DPAPI, journaux, outils et sessions : %LOCALAPPDATA%\Temhalo. Les outils vérifiés sont réutilisables hors ligne.
Pour mettre à jour : arrêter Temhalo, extraire la nouvelle version dans un nouveau dossier, puis la lancer. Les données du profil restent conservées.
Pour retirer l'application : fermer Temhalo et retirer son dossier. Conserver le dossier %LOCALAPPDATA%\Temhalo pour garder les réglages et les clés chiffrées.

Stream Deck : l'installeur propose le plugin si Stream Deck est détecté. En portable, ouvrir plugins/streamdeck/Temhalo.streamDeckPlugin. Les profils et les touches sont gérés par Stream Deck. La touche Démarrer / arrêter commande le relais Temhalo ; OBS reste indépendant.

Version de validation non signée. Les essais locaux ne remplacent pas la validation sur vos plateformes ni sur une machine Windows vierge.
Les licences et notices des composants fournis figurent dans Licenses/, Assets/Fonts/Licenses et THIRD-PARTY-NOTICES.md. Les outils média sont acquis directement auprès des projets amont et conservent leurs propres notices dans le cache.

Délai affiché = délai ajouté localement. Les lecteurs et plateformes ajoutent leur propre latence. Augmenter le délai relit l'historique disponible ; une pause complète seulement l'historique manquant. L'historique RAM est glissant et limité en mémoire.
