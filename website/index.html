Guide rapide

Votre premier live,
dans le bon ordre.

OBS envoie le flux à Temhalo. Temhalo le transmet à vos plateformes.

  1. 1

    Installez Temhalo

    Lancez l’installeur Windows. Gardez l’option Stream Deck cochée si vous l’utilisez.

  2. 2

    Ajoutez vos plateformes

    Ouvrez Diffusion, puis renseignez votre clé de stream. La connexion de compte est aussi disponible si OAuth est configuré.

  3. 3

    Reliez OBS à Temhalo

    Dans Paramètres → Stream, choisissez Personnalisé et utilisez les valeurs ci-contre.

  4. 4

    Lancez et choisissez votre tempo

    Démarrez le relais dans Temhalo, puis le streaming dans OBS. Appliquez ensuite un délai dans Direct.

Avant de vous lancer.

Est-ce que 0 s signifie aucune latence ? +

0 s demande le minimum de délai ajouté par Temhalo. OBS, le réseau, la plateforme et le lecteur conservent leur propre latence. Le délai affiché dans Temhalo mesure le moteur local.

Que voit le public quand j’ajoute du délai ? +

Avec assez d’historique, le flux revient sur un passage déjà reçu et le rejoue, audio compris. Si la réserve est trop courte, Temhalo complète avec des pauses par paliers. Le comportement du lecteur varie selon la plateforme : l’absence de coupure ne peut pas être garantie.

Faut-il configurer une application développeur ? +

La clé manuelle est utilisable directement. Pour « Connecter mon compte », les identifiants OAuth doivent être configurés chez Twitch, Google/YouTube ou Kick. Le dépôt fournit le guide ; Kick demande aussi un service serveur pour son secret.

Quelle mémoire prévoir pour cinq minutes d’historique ? +

À 8 Mbit/s, cinq minutes représentent environ 300 Mo de média, auxquels s’ajoute le fonctionnement du moteur. L’historique est borné par la limite mémoire configurée ; il continue de se constituer à 0 s. Il ne constitue pas un enregistrement permanent sur disque.
