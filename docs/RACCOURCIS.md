# Anciens raccourcis clavier

Les raccourcis globaux et la page Vos commandes ont été retirés de la version simplifiée.
Aucun raccourci Windows n'est enregistré, y compris si un ancien profil les activait.
Le code 1409 des versions antérieures ne concerne donc plus la nouvelle application.

Utilisez les commandes de Direct ou les touches du plugin Stream Deck.
Voir [le guide rapide](DEMARRAGE-RAPIDE.md).
